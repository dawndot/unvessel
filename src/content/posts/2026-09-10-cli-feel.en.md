After the blog was up, the first thing I did was not write posts — it was
forging the site a command: `unv`.

A friend asked whether it was worth it; doesn't `npm run new` create drafts
just as well? It does, but the feel is wrong. `npm run new "title" -- --tags
essay,tools` — those extra dashes are a small speed bump; every time I hit
them I pause to check whether they are about to swallow an argument again.
The shape of a tool shapes the rhythm of the work. Where the friction is
small but the passing is daily, it deserves to be paved flat.

## Three Letters of Distance

`unv new "title"`, Enter, and the draft lands. `unv publish title`, and the
draft becomes a post. Hands never leave the home row; eyes never leave the
terminal.

What Hexo taught a generation of bloggers is simple: **publishing should
feel like speaking.** `hexo new`, `hexo g`, `hexo d` — short to the point of
instinct. I carried that feel over, and added one thing Hexo never had — a
state machine between draft and published: by default a post is a draft,
invisible to the site no matter how long it takes; one command to publish,
idempotent, safe to run twice.

## A Lesson in One Comma

Of course, feel is not declared; it is tested.

The first time I ran `unv new --tags essay,tools`, the tags came out as a
single tag: "essay tools". Half an hour of digging later the cause surfaced:
when the Windows command-line shim forwards through cmd.exe, commas are
treated as separators and quietly turned into spaces. Under node directly,
everything works; put a command name on and it breaks — the kind of bug only
real use collides with.

The fix took one line: split tags on commas and whitespace together, so
however cmd mangles them they can be recovered. But the lesson is worth
keeping: **an interface built for human hands must be typed by human hands
at least once.** Automated tests can prove the logic is right; they cannot
prove the feel is.

## Seen, Not Defined

This blog is called Buqi; its slogan is "Seen, not defined." A command line
is a kind of buqi too — it does not dictate how you write, where you write,
or what you write with; it only offers the shortest path, when you need one.

This very post was published with it.
