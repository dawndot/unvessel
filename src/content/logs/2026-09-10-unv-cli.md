有了全局命令 `unv`（全名 `unvessel`）：new / list / publish / dev / build / preview，博客任意子目录内可敲，项目外执行中文报错。

草稿状态机补齐：建稿默认草稿不进站点，`unv publish` 一键发布、幂等。实测全流程时抓到一个 Windows 专属 bug——cmd shim 转发参数会把逗号吞成空格（`随笔,工具` 变 `随笔 工具`），标签解析改为逗号空白同切后修复。

教训写进了同日发布的文章《命令行的手感》：给人用的接口，必须用人的手敲一遍。
