## 标志性瞬间

- **开机序列**：字体就位 → `is-live` 一瞬间，血条 steps(20) 逐格充能、金币滚到 9999、打字机开始念台词 —— 游戏机的"通电感"
- **彩虹巨字**：六色渐变裁进 Press Start 2P 字形，7s steps(21) 逐格流动
- **低分辨率星空**：canvas 后备分辨率只有屏幕 1/3，拉伸后每颗星是 3px 大像素 —— 彩色星 + RGB 星云 + 滚动视差 + 三态硬闪
- **CRT 电视机层**：扫描线 + 暗角 + 3% 荧光微闪，盖在一切之上（z 900）—— 观众隔着玻璃管看游戏

## 技术要点

- **零依赖**：单 HTML + CSS + 原生 JS；全部"3D"是低分辨率 canvas 的拉伸错觉
- **像素画管线**：字符矩阵（`'..gggg..'`）→ `paint()` 一格一色块 → canvas 后备分辨率 = 矩阵边长 → CSS 放大 + `image-rendering: pixelated`，整数倍缩放零糊边
- **数据驱动配色**：关卡卡内联 `--clr`，精灵主色运行时从卡片读取 —— 换色即换整套精灵
- **steps() 哲学**：全站无丝滑缓动；闪烁用离散相位（`floor(t/400) % 3`）而非 sin
- **无障碍**：canvas 全部带 aria-label / aria-hidden；`prefers-reduced-motion` 下星空静帧、果冻不呼吸、打字机直出全文、血条直接充满
- **省电**：页签隐藏即 `cancelAnimationFrame` 停星空
