# 设计稿归档（五稿对照）

> 本目录是 unvessel（不器）博客的全部设计概念稿。每稿都是**零依赖静态 HTML 活稿**，
> 可直接双击打开或起本地服务预览。最终选定 **v2 墨渊**，已落地为根目录 Astro 工程（`src/`）。
> 其余各稿保留作方向对照与未来素材库（v3 的 Three.js 场景、v5 的像素管线在炫酷层可能复用）。

## 五稿总览

| 目录 | 方向名 | 气质 | 技术要点 | 状态 |
|---|---|---|---|---|
| `v1-paper-ink/` | 纸·墨·朱 | 宣纸文艺、宋体巨字、墨滴画布 | 原生 Canvas blob 墨滴系统、双主题 | ✗ 被否（气质方向不对，04 章） |
| `v2-ink-void/` | 墨渊 INK VOID | 纯黑渊底、视口巨字、日式锋利 | 原生 WebGL 三层 fbm 流体墨、朱砂唯一强调色 | ✓ **选定，已落地 `src/`** |
| `v3-clayverse/` | 未器之城 CLAYVERSE | 暖白黏土、克莱因蓝、轻盈可玩 | Three.js 漂浮器物群、滚动驱动相机、射线交互 | 备选（炫酷层素材） |
| `v4-atelier/` | 不器工房 ATELIER | AE86 海报、三色 Riso 印刷、机务狂热 | 像素栅格化、固定种子做旧颗粒、canvas 线框球 | 备选 |
| `v5-quest/` | 不器 QUEST | 炫彩 16-bit RPG、荧光全彩 | 字符矩阵像素画管线、1/3 分辨率星空、打字机 | 备选 |

## 预览方式

任一子目录都是独立静态站：

```bash
# 以 v2 为例（端口可自选）
npx --yes serve design/v2-ink-void -l 4200
```

历史预览端口：v1 4173 / v2 4200 / v3 4300 / v4 4400 / v5 4500。

## 与工程的关系

- **v2 是设计令牌的权威来源**：`src/styles/global.css` 移植自 `v2-ink-void/assets/style.css`；
  `src/scripts/ink.js` 移植自 `v2-ink-void/assets/ink.js`（已做 ClientRouter 幂等适配）。
  改视觉基调时，先在 v2 活稿验证再移植，比直接改工程快。
- 各稿 README 内有该稿的完整设计说明（令牌表、标志性瞬间、校验记录）。
- 概念稿不参与 Astro 构建（不在 `src/` 内），仅作设计资产留存。
