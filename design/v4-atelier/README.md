# UNVESSEL v4「不器工房 ATELIER」概念稿

> 复古像素印刷 HUD 风 —— 第四方向，与前三稿完全不同谱系。

## 这是什么

一张「头文字D 车库海报」式个人博客首页概念稿。三色 Riso 印刷（暖黑 / 锈红 / 米黄）+ 8-bit 像素巨字 + 街机仪表读数 + 日英双语衬注 + 全屏做旧颗粒。

**审美锚点**：用户提供的 AE86 / CYBER DRIVE 复古印刷海报（黑底锈红米黄、像素字、DATA CARD、HUD 条、做旧噪点）。

## 标志性瞬间

1. **像素「器」字**（`#px-vessel`）：衬线 900 字重的「器」被栅格化成锈红像素块，固定种子随机 12% 残缺 + 8% 米黄套印 + 420ms 微量闪烁 —— 器之未成、永不定型。
2. **UNDEFINED METER 99%**：把海报的 TOUGE RATING 反转成「未定义度」仪表 —— 数值越高越自由。
3. **DATA CARD**：规格表把人量化成参数，唯独 `DEFINITION: NULL — 不被定义`，主题与印刷语言合二为一。
4. **线框球 + 轨道卫星**（`#orb`）：纯 canvas 手写 3D 投影，可拖拽带惯性，锈红轨道上一枚像素方块运行 —— 未定形仪。

## 技术要点

- 零依赖：无 Three.js、无构建。字体四件套（Press Start 2P / VT323 / Noto Serif SC / Noto Sans SC）走 fonts.loli.net 镜像。
- 做旧三层：`body::before` 泛黄斑驳暗角 → `.grain` SVG feTurbulence 噪点（overlay 混合）→ 内容层的细描边直角卡。
- 显现缓动全用 `steps()`：位移分 9 帧跳变（CRT 截图感），仪表条 24 帧逐格充能。
- 降级：无 JS 仍有完整排版与宣言；`prefers-reduced-motion` 一切静止；固定种子伪随机（mulberry32）保证每次刷新残缺图样一致 —— 像同一块印版，不是雪花屏。
