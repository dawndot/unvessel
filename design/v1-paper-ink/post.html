墨的十种死法：一个水墨 shader 的调试笔记

2026-09-02·约 12 分钟· #GLSL#生成艺术#踩坑

墨是活的。它在宣纸上洇开的那一刻，同时在发生三件事：扩散、渗透、蒸发。 想用着色器骗过人眼，就得把这三件事都装进同一个片元着色器里—— 而它们中的每一个，都有一百种方式让画面变成一团死灰。 这篇文章记录我把水墨效果调活之前，它死去过的十种方式。

一、噪点太密：墨成了铁灰

第一版里我把 fBm 噪声的八度数开到 6，以为是细节。结果墨色均匀得像喷墨打印机—— 真实的墨从来不是均匀的，它有浓淡、有飞白、有突然洇开的一坨。 后来把八度降到 3，再让亮度参与噪声权重，墨才有了呼吸。

二、扩散没有边界衰减

墨滴落在纸上，边缘应该比中心淡。我用的是距离场平方衰减，而不是线性衰减—— 线性衰减会让边缘出现一圈可疑的「描边」。正确的手感来自 smoothstep(0.0, 0.7, 1.0 - dist * dist) 这种不光滑的式子。

「君子不器。」 ——《论语 · 为政》。器有定形，墨没有；调 shader 的人最好也没有。

三、洇开的速度是匀速的

真实的墨在落纸头 200 毫秒内扩张最快，然后骤减。我用指数缓动模拟： 半径每帧向目标值靠近 0.4%。写完这句话只用了十秒， 调到手感正确用了三个晚上——参数不是算出来的，是看出来的。

四、笔触的边缘太「干净」

直线段拼接的路径永远画不出毛边。最后的方案是给每条边叠加两层低频扰动： 一层管大形状的歪斜，一层管细小的须状渗出。代码反而变简单了： 

// 边缘扰动：两层噪声叠加，低频管形、高频管须
float edge(float d, float t) {
    float warp  = noise(d * 3.0  + t * 0.2) * 0.35; // 形的歪斜
    float fuzz  = noise(d * 24.0 - t * 0.7) * 0.08; // 须的渗出
    return smoothstep(0.2, 0.9, d + warp + fuzz);
}

剩下的六种死法——帧率抖动、色彩空间错位、混合模式选错、 时间步长撕裂、DPI 忘了乘、以及在 M1 上偷偷溢出的精度—— 等正式动笔再写。写这篇示例只是为了展示正文排版： 标题、引用、代码块、插图与分隔符。
