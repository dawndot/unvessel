# unvessel · 不器 —— 设计稿说明

> 「纸 · 墨 · 朱」：宣纸为底，墨为动，朱砂为印。
> 愿被看见（巨字与对比），不被定义（墨迹永不静止、删除线的「定义」、拒绝卡片式布局）。

## 这是什么

一份**静态 HTML 高保真设计稿**（活稿），不是图片稿。特点：

- 零依赖、零构建：纯 HTML/CSS/JS，双击即可打开
- 动效真实可感：墨迹画布、跑马灯、滚动显现、自定义光标
- 明暗双主题内建：`墨白`（默认，跟随系统偏好）/ `墨夜`，右上角圆钮切换
- 所有序号/日期/文章为**示例内容**，正式站点由文章集合渲染

## 设计令牌（style.css §01）

| 令牌 | 墨白（浅） | 墨夜（暗） | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#f4efe6` 宣纸暖白 | `#141311` 墨夜黑 | 页面底色 |
| `--ink` | `#211f1a` 暖墨黑 | `#e8e2d6` 宣白 | 正文与标题 |
| `--accent` | `#b5382a` 朱砂 | `#d4553d` 朱砂（提亮） | 印章/下划线/强调，**仅点缀** |
| `--ink-2/3`、`--line` | 同色降透明度 | 同 | 次级文字/分隔线 |
| `--canvas-ink` | `33, 31, 26` | `232, 226, 214` | 画布墨色（裸 RGB，供 JS 拼 rgba） |

结构令牌：`--measure: 42rem`（中文行长）、`--wide: 72rem`（版心）、8px 基准间距、`--ease` 统一缓动。

## 字体策略

设计稿用系统字体栈保证离线可看。正式站点（Phase 1）计划：

- 中文标题：**霞鹜文楷 / 思源宋体**（开源可商用），按需**子集化**（中文字体必须子集，否则数 MB 不可接受）
- 英文点缀 / 元信息：等宽字体（JetBrains Mono / IBM Plex Mono）
- 正文：系统中文字体优先，零加载成本

## 与 Astro 的映射（Phase 1 移植清单）

| 设计稿元素 | Astro 组件 |
| --- | --- |
| `#ink-canvas` + site.js 画布 | `<InkCanvas />`（client island，`transition:persist` 跨页不断渲染） |
| `.topbar` | `<Header />` |
| `.post-list` | 文章集合渲染的 `<PostList />` |
| `.prose` | 文章布局 + `@tailwindcss/typography` 或自写 prose 样式 |
| `.grain` / `.footer` / `.marquee` | 全局布局组件 |
| style.css §01 tokens | `global.css` CSS 变量（保持原样即可） |

## 无障碍底线（正式站点必须遵守）

- `prefers-reduced-motion: reduce` → 画布静帧、无跑马灯、无位移动画（已实现于 CSS/JS）
- 移动端：禁用自定义光标；墨滴更小更淡（`data-quiet`）
- 对比度：正文对纸底 ≥ 12:1；朱砂仅用于大字号点缀与图形元素
