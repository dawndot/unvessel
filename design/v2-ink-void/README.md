## 为什么推倒 v1

v1（`../design/`，纸·墨·朱）的问题是**气质方向**而非执行精度：
宣纸文艺向与目标参照系（Awwwards 获奖站 / bruno-simon 式 3D / 日式极简锋利）
不在一个频道。v1 保留在 `../design/` 作对比，不再迭代。

## 方向定义：墨渊 INK VOID

一句话：**纯黑渊面 + 视口级巨字 + WebGL 流体墨 + 朱砂唯一彩色。**

| 维度 | v1 纸·墨·朱 | v2 墨渊 INK VOID |
| --- | --- | --- |
| 底色 | 暖白宣纸 `#f4efe6` | 纯黑渊底 `#070707` |
| 主题 | 双主题（墨白/墨夜） | **单主题，只有黑**——气质即立场 |
| 巨字 | 编辑部式标题（宋体） | 视口级 900 黑体巨字 + Anton（拉丁） |
| 背景 | 静态纸纹 + 墨点 | 原生 WebGL 流体墨（三层域扭曲 fbm） |
| 彩色 | 朱砂 `#b5382a` 常规使用 | 朱砂 `#ff3b2f` 提亮，**唯一彩色，出现即强调** |
| 形状 | 圆角/柔和 | 全直角、1px 发丝线、无投影 |
| 交互 | 温和 hover | 整行反白（朱砂底从下生长）、自定义光标、巨字视差 |

## 设计令牌（style.css `:root`）

- `--void: #070707` 渊底 · `--bone: #f2f0ea` 骨白 · `--smoke: #8a8781` 烟灰
- `--line: rgba(242,240,234,.16)` 发丝线 · `--accent: #ff3b2f` 朱砂
- 字体：`Noto Sans SC`（900 巨字/正文）、`Anton`（拉丁展示）、`JetBrains Mono`（编号/坐标/标签）、`Noto Serif SC 900`（宣言重音）

## 关键实现说明

- **流体墨**（ink.js）：一个全屏三角形 + 三层域扭曲 fbm 把噪声拉成墨丝；
  指针位置经迟滞插值后搅动坐标（高斯衰减的旋转+外推），朱砂层由另一路
  低频噪声控制、在指针附近加权——「墨被搅开时朱砂才浮上来」。
  工程兜底：DPR 钳制 1.5、页签隐藏停帧、`prefers-reduced-motion` 只渲染
  一帧静帧、WebGL 不可用自动降级纯色渊底、上下文丢失恢复。
- **入场编排**（main.js + style.css 11 节）：Hero 等字体就绪（900ms 兜底）
  才播入场，杜绝 v1 出现过的字体交换跳动；其余区块用 IntersectionObserver
  单次触发 `data-rv` 显现。
- **字体加载**：开发期用 fonts.loli.net（Google Fonts 国内镜像，按
  unicode-range 切片）；**正式 Astro 站改为自托管子集化 woff2**
  （工具：cn-font-split / fontmin），并加 `<link rel="preload">` 首屏两个字形片。
